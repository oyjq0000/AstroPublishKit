# Third-party notices

AstroPublishKit was designed after auditing a private production blog whose reusable publishing infrastructure includes MIT-licensed work derived from **AnvilWiki** (`PNGTRID/AnvilWiki`).

The AstroPublishKit repository uses a new Git history and does not include the private blog's content, migration archives, deployment history, analytics identifiers, redirects, or branding. Where the implementation is materially adapted from the AnvilWiki-derived publishing infrastructure, the upstream MIT copyright notice is retained in `LICENSE`.

The following projects were researched as feature/design references but their theme/component source was not copied into the initial AstroPublishKit implementation:

- `satnaing/astro-paper` — MIT
- `saicaca/fuwari` — MIT
- `radishzzz/astro-theme-retypeset` — MIT
- Cloudflare's Astro starter and public deployment documentation

See `reference-projects.md` and `source-audit.md` for the engineering provenance record.
