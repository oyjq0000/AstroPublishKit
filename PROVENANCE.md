# Provenance

AstroPublishKit has an independent Git history and is maintained as a standalone publishing starter.

The project was informed by an audit of an existing Astro publishing site and by research into public Astro projects. That research was used to identify reusable product ideas and publishing requirements rather than to reproduce another project's visual identity.

Long-lived attribution notes:

- infrastructure patterns derived from AnvilWiki are covered by the upstream MIT notice preserved in `THIRD_PARTY_NOTICES.md`;
- AstroPaper, Fuwari and Retypeset were reviewed as public reference projects during product research;
- no source code from those reference themes is represented here as copied theme code;
- private production content, credentials, analytics identifiers and source Git history are not part of this starter.

`THIRD_PARTY_NOTICES.md` is the authoritative record for third-party license notices that must remain with redistributed copies.
