# Contributing

Keep AstroPublishKit generic, static-first, and safe to publish.

Before opening a pull request:

```bash
npm install
npm run check
```

A contribution should not add personal site content, live analytics IDs, secrets, migration archives, or source-project branding. Optional services must remain disabled when their environment variables are absent.

For significant new features, update `feature-matrix.md` or document why the v1 scope has changed.
